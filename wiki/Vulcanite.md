A Vulcan-based game engine, started to gain an understanding of the API based on the [Vulkan Guide](https://vkguide.dev), then extended to include an [[Entity Component System]], [[WebGPU]] rendering, and modern rendering techniques.

This is, and will remain, a learning experience. Don't expect professional quality or performance. That being said, it was designed from the start to use modern industry techniques such as an [[Entity Component System|ECS]], and bindless/GPU-driven rendering. Some of these techniques involve using the unconventional/weird/modern/"mathematics is discovered not invented" way.

See [[Building]] for complication instructions across all supported platforms.
